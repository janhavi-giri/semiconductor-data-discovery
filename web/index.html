Prediction input rules

Customer walkthrough · 8–10 minutes

A file location is only the beginning.

Demonstrate the difference between storing a file and making it usable by an application.

Presenter flow

1. State the engineering question“Find etch traces for failed wafers from chamber C2.” This is the synthetic scenario.
2. Compare discoveryShow opaque filenames, then matched context. Inspect one result to expose exact metadata, evidence and linked test outcome.
3. Show trust and boundariesSwitch to real SECOM and ask for chamber C2. There are no matches because that identity is unavailable.
4. Export an application contractSelect traces and download the handoff. Show source paths, checksums, roles, join keys and limitations.
5. Connect to manufacturing practiceDiscuss which MES, FDC, metrology and test sources supply authoritative identities and relationships in a customer pilot.
Describe this as a discovery PoC. The demo illustrates discovery with synthetic records, curated lexical search and a single ML baseline.
