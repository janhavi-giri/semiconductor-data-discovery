# Contributing

Keep real public data and synthetic data explicitly separated. Do not add private customer data or credentials. Preserve dataset attribution. New metadata must distinguish source evidence, computed profiles, curated meaning and unknown fields. Add a meaningful behavioral test for discovery or contract changes and run `python -m unittest discover -s tests -v`.

The server is for a local demonstration. Enterprise authentication, authorization, source connectors, watchers and scalable indexing require separate design and implementation.
